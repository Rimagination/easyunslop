# easyunslop · 学术表达精修

用于中文和英文论文、摘要、学位论文及其他专业文本的编辑 skill。清理 AI 腔、黑话、套话和冗余，改善句子重心与段落衔接，同时保留原意、专业术语、证据强度和学术语域。

适用于已有文字的润色。经验研究、理论与形式研究、人文阐释和规范论证各自保留其概念与行文惯例。清楚、准确的原句可以保留。

## 编辑时关注什么

- **表达质量：** 让研究对象、主要动作、比较关系和已有发现更容易把握。
- **学术准确性：** 保留因果与相关的区别、量词与否定范围、数值单位、引用归属和作者立场。
- **专业性：** 根据语境处理术语、名词化、被动句和长句，不用口语化或降低术语密度衡量质量。
- **信息边界：** 从已提供的材料中理顺关系；不补造结果、机制、文献，也不因用户未附某项检验便给正文增加“未做检验”的判断。
- **充分而克制的修改：** 清除确定无信息的包装，复读修改后的完整句段；没有明确收益的改动撤回。

工作方式是三轮轻量编辑：定位表达问题、作最小充分修改、对照原文复读。默认直接交付正文；用户要求时提供对照与理由。

## 安装与使用

将本仓库克隆到你所用工具的 skills 目录，文件夹名保留为 `easyunslop`。在该 skills 目录中执行：

```sh
git clone https://github.com/Rimagination/easyunslop.git easyunslop
```

也可以从 [Releases](https://github.com/Rimagination/easyunslop/releases) 下载 `easyunslop-v0.1.0.zip`，解压后将 `easyunslop` 文件夹放入 skills 目录。目录内应直接包含 `SKILL.md`、`agents/` 和 `references/`。Codex 使用自定义 `CODEX_HOME` 时，可安装到其 `skills` 子目录；以当前工具实际加载的路径为准。

调用示例：

```text
请用 $easyunslop 润色以下论文段落，去掉 AI 腔和冗余，保持专业性、
学术规范、原意与证据强度。直接给出改后的正文。

[粘贴待改文字]
```

需要控制修改幅度时，可补充“只改措辞与句间衔接”或“允许调整段内顺序”。需要修改摘要时，一并提供正文中的研究对象和主要发现，有助于准确组织重点。

## 一个例子：地球与环境研究

以下是项目自编的虚构教学材料。

**原文**

> 从比较结果的层面来看，2011—2020 年，流域北部站点观测的年平均降水量为 820 mm，南部站点为 760 mm。我们使用空间分辨率为 5 km 的卫星反演降水产品进行了相应的比较工作。该产品对同一时期北部与南部区域的年平均降水量估计分别为 790 mm 和 750 mm。需要指出的是，站点观测值与格网区域平均值在空间代表性方面存在差异。

**改文**

> 2011—2020 年，流域北部站点观测的年平均降水量为 820 mm，南部站点为 760 mm。我们使用空间分辨率为 5 km 的卫星反演降水产品进行比较。该产品对同一时期北部与南部区域的年平均降水量估计分别为 790 mm 和 750 mm。站点观测值与格网区域平均值在空间代表性上存在差异。

这处编辑压缩了铺垫，保留时间、数值、单位、空间分辨率，以及站点观测与格网区域反演的区别。该输出来自已记录的[行为检查](docs/validation.md)。

## 质量依据

检查原文与改文的含义、专业概念、证据强度和表达收益。AI 检测分数与黑话命中数量不作为质量标准。

目前保存了 5 项自编材料的独立代理编辑记录，覆盖摘要、工程比较、规范论证、数学和地球与环境；另完成一次规则综合审查。见[输入](docs/inputs.md)、[输出](docs/outputs.md)与[验证记录](docs/validation.md)。真实案例用于提炼编辑方法；本版本尚无真实作者或目标读者对技能输出的盲评结果。
