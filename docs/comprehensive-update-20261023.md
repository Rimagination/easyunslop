# 综合补充：写作方法、作者声音与混合语言诊断

本次核查围绕已有稿件的语言编辑：哪些方法能解决具体阅读困难，哪些做法容易损伤专业含义，现有规则和工具哪里仍有遗漏。资料包括大学写作中心、专业编辑标准、AI写作研究及社区项目；[来源与采用边界](../references/sources.md#结构语法与作者声音的补充方法)区分了实践指导、实证研究、预印本和社区经验。

## 本次接入与强化

| 方法 | 落入编辑流程的动作 | 保留条件 |
|---|---|---|
| 反向提纲 | 长稿结构难跟随时，概括相关各段的主题与职责，找出前提滞后、一段多任务和职责重复。 | 不假定主题句在段首；跨节调整按授权。 |
| 非相邻语义重复 | 比较重复处有没有新证据、条件、推理层次或任务，合并无新增作用的复述。 | 摘要概括、结果报告、讨论解释各有任务；不同分母与条件不合并。 |
| 句间信息承接 | 检查主题、指称与新信息的关系，调整主语、语态或短语位置，再选择必要的连接语。 | 不统一句式，不强制重点句末；准确的术语复现可以保留。 |
| 文献段综合 | 依据所给研究的问题、方法或结果组织关系，保留每条引用的支持对象。 | 不从题名、年份或少数论文制造共识、趋势和机制。 |
| 英文指称与语法 | 按所指对象检查冠词、可数性、一致关系、悬垂修饰和限定性从句。 | 不机械采用首次a、再次the；拆并句不改变动作主体与样本子集。 |
| 按功能选择时态 | 分辨完成的操作、特定观察、图文陈述、当前解释和计划。 | 合理切换继续保留，不将一次观察改为普遍规律。 |
| 正文与图注分工 | 用已有信息说明图表对象、单位、缩写、统计量与误差含义；正文保留关键比较。 | 不猜样本量、SD/SE/CI，不删掉不利结果。 |
| 作者声音与立场 | 从原稿好段落或所给样稿辨认人称、评价与展开习惯，回查批评、让步和结尾。 | 不从作者身份推测文风，不强加中立、乐观或强烈语气。 |
| 跨节套式与解释尾句 | 检查重复开场、统一拔高、泛泛展望及解释尾句是否增加无依据的新判断。 | 真实分类、平行实验、法律条款和已有推论继续保留。 |
| 可执行的检查意见 | 定位读者在哪一步难以判断什么；主编辑先查稿件是否已有答案，再决定移动、改写或不采纳。 | 泛泛的“缺乏深度”不触发补造内容；代理反馈按实际身份记录。 |

作者声音、语域、引用归属及多代理分工原来已有。本轮将它们落实为更具体的检查动作，合并进原来的组织、句子和复核环节，没有追加必须完成的轮数或评分门槛。[教学实例](../references/editing-examples.md)由25例增加到33例；新增8例均为自编材料，包含需要改写与应当保留的部分。

## 工具修复

本轮先用最小输入复现三个遗漏，再修改原有标准库脚本，未引入依赖或另一套扫描器。

1. **混合语言漏扫。** 自动模式现在分别扫描可识别的中英文；双语参照按各语言贡献对应统计单位。保留原有JSON字段，并增加`scan_languages`和各统计块的有效参照列表；显式`--lang zh/en`继续限制语言。
2. **行内强调割裂词组。** 常见Markdown、LaTeX和HTML行内强调保持自然语言连续与原位置；代码、公式、块标签和中文片段继续阻断英文词组拼接。
3. **参考文献污染正文统计。** 排除常见`thebibliography`与biblatex输出及引用键，保留其后正常章节。文档清洗仍有明确边界，自定义宏和异常嵌套需回查原稿。

实现者在三项修改完成后运行一次现有自检：

```text
python scripts/check_lexical_scan.py
PASS: lexical scan, cleaning, profiles, normalized reference rates, and input protection
```

新增断言覆盖双语稿与双语参照、显式语言限制、六种常见排版写法的一致计数、块级分界及参考文献隔离；原有输入保护、历史词库标签和相对频率检查保留。

最终综合审查又发现一处引用参数范围的回归：普通`\cite`或`\parencite`后紧接花括号正文时，原清洗表达式可能把正文当作额外引用参数排除。修复后，普通引用只消耗一个必需参数，明确的多来源引用命令如`\autocites`单独处理多个参数。补入正文分组保留断言后重跑同一脚本自检，通过。

## 两份新稿的实际试用

独立执行者按新版技能处理了中文行政法论证与英文地球环境研究稿，两份均为自编模拟材料。主编辑先各运行一次原稿扫描，再对同版两稿执行表达与保义检查；两位检查者均未发现可确认的问题，主编辑保留初改并各复扫一次。完整输入与输出见[整稿试用记录](comprehensive-trial-20261023.md)。

| 稿件 | 实际修改 | 实际保留 |
|---|---|---|
| 中文规范论证 | 将“实质回应”的定义移到本节使用之前，合并重复解释，压缩空泛开场。 | 批评立场、“应当”的义务强度、适用范围、说明理由与同意主张的区别，以及回执的实际作用。 |
| 英文地球环境稿 | 校改冠词、可数性、主谓一致和修饰主体，整理流量资料的承接，用所给方法与图示信息完善图注。 | 站点与采样口径、差值方向、配对bootstrap、均值与区间、低于检出限样本的保留方式、2027年计划，以及图中点和菱形的不同含义。 |

英文稿前后都没有词库命中，仍存在可以改善的语法、结构和图注。这个结果也说明编辑不能停留在找词替词。此次未设置无技能或竞品对照，两份模拟稿不作跨学科普遍优势的证明。

## 按语境选用的方法

句子长短、被动句、名词化、正式词汇和重复本身都不判为质量问题。保留专业含义和合理的学术惯例，再解决具体的主干、搭配、衔接与冗余问题。未采用全面禁用副词、固定标点配额、刻意加错、虚构个人经历、凭空增加细节等做法。

AI写作研究用来提醒立场漂移、模板化和文风收敛等风险；模型、任务、语言和参与者范围随来源记录。词频升降、代理一致或教学例数量均不能推出“全面优于竞品”。日常改进依据实际稿件与编辑失误完成，不等待真人评价才修复已知问题。


## 本批验证范围

- 脚本实现者完成三项修复后运行一次 `check_lexical_scan.py`，通过；综合审查发现引用参数范围问题，修复后再跑同一自检，通过。两次对应不同代码状态，没有在相同状态重复执行。
- 最新版技能入口经 `python -X utf8 .../quick_validate.py` 检查，返回 `Skill is valid!`。Windows默认GBK读取曾失败，改用UTF-8模式后通过；此问题来自校验器的默认解码方式。
- 模式编号唯一，33个教学例连续，技能内23处本地链接有效。发布文档共69处本地导航链接，以及README代码围栏、折叠区、引语和Logo检查通过。
- 两份模拟整稿共运行四次扫描，并完成同批表达与保义检查；没有为增加轮次另写替代终稿。

本项目没有软件构建流程；未运行无关构建、重复的历史行为检查或哈希检查。独立综合审查集中在本批规则、示例、工具与记录，未对每个小改动另设双审。

综合审查确认的唯一问题已由实现者直接修复并局部验证，其他指定范围未发现交付问题；没有另开整稿复审。常见文档清洗的格式边界继续保留在工具说明中。
