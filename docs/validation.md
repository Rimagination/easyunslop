## 证据范围

这些检查提供有限的行为证据。真实论文案例用于核实公开修订并提炼方法；5 项改稿为自编材料。截至 v0.1.0，尚未完成真实作者或目标读者盲评，也未完成同一材料、独立上下文下的无技能对照实验。

本版本由 Markdown 与技能界面元数据构成，没有软件构建或运行依赖。本次沿用已经完成的结构和行为验证，发布环节检查文件内容、相对链接、提交范围与下载包完整性。
