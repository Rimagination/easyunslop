## 编辑规则修订

- 合并重复条款，保留任务范围、内容约束、组织与句法编辑、按需查例及交付要求。

- 技术细节暂不能确定是否可删时，先保留细节并调整句法。语义确有分叉时再提出局部问题。

## 全文协作的实际试跑

主编辑依据新版技能处理一篇约800字的原创模拟地球与环境短稿，范围包括题名、摘要与四节正文。模拟研究涉及8个山地浅水湖、24个站点及12周水温监测。

实际执行顺序：

1. 主编辑保存原稿，形成完整初改稿。
2. 两位全新上下文的子代理并行检查同一版初稿。表达检查者只接收改稿和编辑要求；保义检查者先读原稿，再对照改稿。两者均未获得主编辑的改动理由或对方意见。
3. 主编辑核对建议，统一修改，再定向检查新改动及相关段落。

### 检查意见如何落实

| 检查意见 | 主编辑的实际处理 |
| --- | --- |
| 背景节最后突然转入海拔信息，削弱研究关注点的收束。 | 原建议将地理信息移入方法节，超出本次同节编辑范围；改为在背景节内前移，使段落以近岸研究范围结束。 |
| 7月数值仍沿用全期模型指标的简称，时间层级不够明确。 | 将18.1 °C称为“站点记录的白昼月平均水温”；原稿未交代跨站点汇总算法，编辑未补造算法。 |
| 讨论从后续计划又返回现有依据，段落推进反复。 | 先说明现有解释与数据依据，再交代下一步观测；保留仪器尚未安装的状态。 |

保义检查未发现需返工的实质误改，也未为凑意见数量增加建议。主编辑落实上述三处修改后，对照原稿定向核对，连读题名、摘要、结果与讨论。原稿和终稿的42项数字字面值及出现次数一致，5个二级标题的文本、层级和顺序一致；统计分母、模型条件、观测与反演尺度和计划状态另经文字核对。

## 轻校与工具受限分支

- **英文短段轻校：** 使用一段四句的模拟专业文字，执行者判断其语法、衔接和限定均清楚，原样交付；输出与输入精确一致。
- **模拟无代理工具：** 同一执行者在题设限制下完成全文初改、单读改稿、原文对照和整合，交付完整短稿。数字与标题核对通过。执行者此前已看过协作试跑产物，该任务用于确认顺序流程可执行，不承担独立质量比较。
- **单个可用代理名额：** 已核对顺序委派的规则，本轮没有另开实际试跑。
