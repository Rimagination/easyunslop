# 编辑模式库

本库用于直接改稿。先从完整句子或段落确认问题，再按对应条目处理；同一问题只处理一次。以下信号来自公开编辑资源与原项目经验，不能据此鉴定作者身份。处理办法已按学术语域调整；来源见 [来源记录](sources.md)。

## 1. 基础清理：黑话、套话与机械表达

| 编号与表现 | 具体处理 | 保留条件与易混情况 |
|---|---|---|
| B01 空泛开场：“值得注意的是”“需要指出的是”“从结果层面来看” | 后面已是完整陈述且没有特别提醒作用时删去，直接写结果或观点。 | 真正提示反常结果、关键例外或章节转换时，可以保留提醒。 |
| B02 背景包装：“在……不断发展的背景下”“随着……持续推进” | 背景与本句没有具体关系时删去外壳；有实质背景则直接交代。 | 研究时期、政策条件或技术环境属于论证前提时保留；不能随意删除作者的背景判断。 |
| B03 黑话代替功能：“赋能”“抓手”“底座”“引擎”“闭环”“打通” | 从原文找到已说明的功能、操作和对象，直接表达；例如有查询功能就写谁可查询什么。 | 反馈控制的闭环、数据库引擎、理论中的既定概念等按专业含义保留。仅有抽象主张时不猜测实现方式。 |
| B04 堆叠褒义词：“深刻、全面、多维、系统性、颠覆性”串联 | 删除没有额外含义的修饰；有覆盖范围或具体贡献时用原有内容承接。 | 系统性误差、系统综述、多维尺度分析等术语保留；实质性的首创、全称或范围主张不能静默删除或改弱。 |
| B05 虚化动词：“开展……工作”“进行了……的分析”“作出了……的判断” | 将已有动作放到谓语位置，如“开展访谈工作”改为“访谈”；必要时保留动作对象。 | “进行性病变”等词中的字面命中无关；命名操作、方法名和必要名词化保持完整。 |
| B06 重复限定或强调：“可能或许”“进一步继续”“非常十分” | 多个词作用相同时压缩；分别核对知识、时间、条件、程度和范围的限定，保留各自承担的信息。 | “仅在……时可能有效”包含两种限定；“据我们所知”和“截至写作时”承担不同任务，不能混成一个泛泛的保守语气。限定也不能替代检索。见编辑对照 E04。 |
| B07 空泛贡献复述：“提供重要启示”“具有重大意义”反复结尾 | 前文已给出同一判断时删除重复句；有具体意义时将对应发现与该判断放近。 | 作者提出的理论评价、价值判断和贡献范围属于内容；不能因为尚未核验就全部删掉。 |
| B08 推论词空转：“这意味着—这说明—进一步表明—由此可见” | 看每一步是否增加独立信息；同一结论换说法时合并，真实推理步骤继续保留。 | 证据、解释和结论分属不同层次；不能把它们合并成更强断言。 |
| B09 假转折与假揭示：“看似……实则……”“表面……深层……” | 两端只是同义评价时保留实质判断，取消制造悬念的外壳。 | 真正的假说排除、类别区别和作者对照必须保留；改句法时检查否定范围。 |
| B10 排比凑数、每段统一拔高 | 合并同义修饰与重复判断，让各句承担具体任务；停止在最后一个有信息的判断处。 | 三种独立方法、三项结果、真实分类和刻意修辞可以完整保留；不按数量裁剪。 |
| B11 对话与操作残留：“根据你的要求”“以下是润色版本”“希望有所帮助” | 从论文正文中移除编辑过程、聊天礼貌和自述身份等残留。 | 真实访谈引语、被分析的 AI 对话、研究材料中的提示词按原话保留。占位符不由编辑填造。 |
| B12 模糊权威：“学界普遍认为”“大量研究表明” | 原文已给出具体来源时明确归属；来源或共识范围不清时保留原主张，必要时在正文外指出具体待核项。 | 不能把带来源的判断改为作者的无来源断言；去黑话不承担自动查证，也不以删除归因来制造确定性。 |
| B13 英文填充语与泛化修饰：it is worth noting、a wide range of、valuable insights、delve into | 删除无提醒作用的前缀；重复的泛化描述可压缩；能等义时采用较直接的动词。 | 范围本身有信息时保留；某个正式词并不必然冗余。句子清楚时无需逐词换写。 |
| B14 英文技术词被当成“AI 词”：robust、significant、landscape、framework、leverage | 先分清技术含义与装饰性用法，仅清理后者的冗余。 | 稳健估计、显著性、能量景观、理论框架、回归杠杆值等概念继续使用标准术语。 |

基础清理后应留下信息完整、语法成立的正文。若只把“赋能”替换为“助力”、把“深度洞察”替换为“重要认识”，仍需检查是否解决了原来的空泛问题。

## 2. 句子精修：让信息更容易读懂

| 编号与阅读困难 | 编辑动作 | 复读重点 |
|---|---|---|
| S01 很晚才读到对象和动作 | 找出主干，判断插入信息的作用；保留技术细节后调整位置或拆句，确认无关后才删。 | 条件是否仍限定同一个动作？施事者是否来自原文？不能确定能否删细节时，仍可通过移位改善阅读；语义关系有实质分歧时再请作者决定。见 E01、实例 11。 |
| S02 动作被多层抽象名词包住 | 能等义时将动作恢复为谓语，保留必要的分析对象与术语。 | “考虑采用”仍处于考虑阶段，“评估效果”不等于确认有效，“体现改善”不等于造成改善。 |
| S03 “这、其、该结果”可能指向多个对象 | 用原文已有的对象名、比较或结果名明确指代；可以增加几个必要的字。 | 原文能否确定所指？有真实歧义时不要猜定一个解释。 |
| S04 重点被插入语或次要信息淹没 | 按当前段落的问题重排主句与附属内容；同一主体跨句展开时，可把已有名称放到读者需要辨认的地方。 | 信息重要性依据上下文及作者意图判断；不把“重点放句末”当成固定语法；移动名称时保持资料归属与事件次序。见编辑对照 E03。 |
| S05 两个对象、属性或条件错位 | 把每个属性放回对应对象，明确比较发生在哪些对象之间；同一个专业词可以重复使用。 | 所指必须由原文或配套材料确定。已有数据可恢复关系；缺少对象时不猜补。见真实案例 R03、R04。 |
| S06 符号或缩写反复出现，但其用途难以理解 | 在首次相关使用处安排原稿已有的释义或用途说明；定义明确后继续使用简写。 | “说明符号的作用”与“增加一种计算操作”不同；高频缩写不必每次展开。见 R01、R05。 |
| S07 数值或时空短语的含义难以确定 | 从已提供材料中恢复量的类型、统计对象和时空范围；把时间、空间及条件短语放近其真正修饰的判断。 | 总量与浓度、观测与反演、研究者认识的持续时间与自然过程持续时间保持区别。缺少深度、基准期或变量定义时不自行填入；某处术语修正不触发全篇替换。见 R09、R10、E02。 |
| S08 词语都正式，组合起来却生硬；并列项勉强共用一个谓语 | 分别检查各项与谓语的搭配，再按已有含义重组句子。例如“专业性与作者风格得以保留”可分别表达为“保留作者风格”“遵循专业规范”，并判断上下文是否需要重复说明。 | 再读新句是否改善了具体搭配，避免只换成另一种正式说法；也不把“就……而言”本身当成问题。论证角度与实际条件保留。见实例 18、19、22。 |
| S09 数据、模型、方法之间的支持关系含糊 | 分辨证据支持的是模型本身、采用该模型的理由，还是某项预测；在已提供上下文中选择准确谓语。 | 缺少判断依据时不把“支持”升为“证实”，也不擅自指定支持对象；保留可核对表述，在正文外问作者一个具体问题。见编辑对照 E05。 |
| S10 修复病句时换掉了被测量或检验的对象 | 先区分材料、操作、测量结果与解释，再为原有对象选合适的动作。模型性能与信息量、样本与样本的测定值须保持区别。 | 动词顺了以后，研究问题仍须相同；计划、完成、观察与普遍判断的时态和状态也不互换。见实例 25。 |

## 3. 段落精修：让句子共同完成一件事

| 编号与阅读困难 | 编辑动作 | 复读重点 |
|---|---|---|
| P01 句句通顺，读完关系仍不清楚 | 找出各句已有职责，如定义、材料、比较、解释；让解释对象先出现，再接说明。同节全文润色可分合相邻段、补明已有主体；跨节重排依用户的结构编辑要求执行。 | 概念前提先于依赖它的分析。保留因果、条件、时间和对照关系，不能添加原稿没有的推理桥梁。见 E03、R08。 |
| P02 相邻句换术语复述、段尾重复开头 | 稳定同一概念的名称，合并真正重复的信息，让下一句接着已有对象推进。 | 保留必要的主题句、结论句与跨段提醒；真实变化的指称不强行合并。 |
| P03 摘要只列研究议程，读者找不到发现 | 从用户已提供的正文提取主要发现，按该文体的摘要任务组织；标题保留决定对象范围的限定。 | 不把教学案例的发现搬进用户论文，不统一规定句数或实验论文结构。见 R02。 |
| P04 结果与解释的层次、比较维度来回跳动 | 先识别各句承担的任务，在授权范围内按相同对象或比较维度组织；将解释贴近其对应证据。 | 保持作者的实质推理与学科惯例；材料未报告的新比较或解释需作者提供。见 R04。 |
| P05 开头挤入功能、分类与原则，下一段又用口号重复 | 按这段文字的用途安排信息，让读者先理解对象及用途，再读必要的范围或做法。合并重复宣称；跨段移动独有内容遵守用户授权。编辑规则留在内部，所需的产品功能说明保留。 | 论文摘要须报告已有研究信息，项目介绍须说明用途；不能把两者改成同一种开场。实际分类、必要条件及用户指定的宣传语保留，不强制两段式结构。见实例 18。 |
| P06 拆并句后，引用好像支持了更多主张 | 为每条引用保留明确的支持对象；作者自己的发现、他人结论和被评论者的观点分别表述。文风样稿只提供表达参照。 | 引用键没有丢失，也可能发生归属扩大。只提供引文标记时不猜文献内容。见实例 23。 |
| P07 长稿局部都顺，全稿的术语、数字或力度却变了 | 维护简短内部记录并核对题名、摘要、正文与结论；分批编辑带上相邻段和定义。 | 原稿自身冲突保留并在正文外定位；不静默统一不同数值，不补算每周／累计或不同分母的比例。见实例 24。 |

作者声音通过其用词、评价立场、句法习惯与论述节奏保留。清理共同症状时仍允许不同作者有不同的好写法；不要把所有段落统一成短句、列表或同一结尾。不同章节的任务也有区别：方法须明确操作与条件，结果须明确比较，讨论须区分观察与解释；人文和规范论证按其实际论证结构编辑。

## 4. 题名与节标题：让读者知道将读到什么

| 编号与阅读困难 | 编辑动作 | 复读重点 |
|---|---|---|
| T01 论文题名被“关于……的相关研究”等外壳拉长，或对象范围不清 | 根据所给题名及正文突出研究对象、关系和必要范围；从材料中恢复有依据的限定。 | “研究”“机制”“影响”等词按实际功能判断；保留研究设计、地区、人群与时间等必要信息。关系表述不升级为因果；只给题名时不猜补正文。见真实案例 R02、教学例 15。 |
| T02 节标题只有“相关分析”“进一步讨论”等泛称，难以导航 | 结合本节正文明确其内容或论证任务；同级标题采用与各节内容相称的具体程度和命名方式。 | 只提供目录时可清理措辞，不虚构各节发现；保留层级、编号和引用键，改名后同步所给材料中的目录与按名称引用。见教学例 16。 |
| T03 为了去 AI 味，标题被统一改成口号、短句或结论句 | 按学科、期刊与作者要求保留有效的问句、名词短语、陈述式或主副标题形式。 | “引言”“研究方法”等能准确导航时可保留；明确规定的固定标题按原样使用。不设统一字数、冒号配额或结论式模板。见教学例 17。 |

完整示例见 [编辑实例](editing-examples.md)：10–14 句段精修，15–17 标题，18–22 生硬表达与误改复盘，23–25 引用、稿内冲突与研究对象。公开论文中的实际取舍见 [真实修订案例](real-editing-cases.md)。每个模式用于解决具体阅读困难，不用词表命中或修改数量衡量收益。
