# 词汇诊断：统计、词库与上下文判断

本文件负责词频、重复词组、候选词库及参照比较的执行。任务模式与编辑范围按[主文件](../SKILL.md#确定本次编辑任务)确定；词库的命中用于定位需要回读的位置，具体改法遵守主文件的保护原则。

## 何时扫描

- 实际进行全文或跨节润色时，在任务要求已确认、初改尚未开始时对原稿扫描一次。长稿轻校、短段、单个标题和只诊断不因篇幅或点名技能就强制扫描；用户明确要求词汇诊断时按请求执行。
- 完稿后，正文、标题或图表说明有语言改动时，对终稿再扫描一次并回读相关上下文，查已处理的重复及新出现的包装；纯格式变化或文本未改时沿用已有结果。
- 扫描由主编辑统一执行，不每轮、每段或每位检查者重复执行。工具只读待改文本；没有 Python 时按下文人工检查，继续完成编辑。

## 一次扫描提供什么

- 稿内高频英文实词、二三元词组，以及中文二三元字组。默认`--lang auto`分别扫描稿内可识别的中英文，混合稿同时保留两类词库候选与统计；指定`--lang zh`或`--lang en`可限制语言。中文统计没有分词，半词与领域词须回到原句判断；英文词组不跨中文片段、句子或段落拼接。
- [候选词库](lexical-signals.json)中词句的命中次数、位置和上下文，以及对应的检查动作、保留条件和来源。词库条目命中一次也会提示，不受重复词最小次数限制。
- 提供匹配参照目录时，比较归一化频率，区分两侧均出现和只在目标稿出现的候选。没有参照时，仍可运行稿内统计与词库扫描。

默认剔除代码、URL、公式、引用键及参考文献节，包括常见`thebibliography`和biblatex输出；随后正常章节继续扫描。自然语言标题和图注参与扫描。常见Markdown加粗/斜体、LaTeX的`emph/textit/textbf`及HTML行内强调不割裂词组，位置仍对应原稿；块标签、代码和公式保持分界。文档清洗覆盖常见写法，自定义宏和异常嵌套仍需核对。稿内高频词可能就是研究对象，原句需按实际含义判断。

通常读取报告中命中的条目即可，词库由脚本加载。短段按具体问题选读，不默认通读整份词库。

## 执行

在技能目录中运行，实际调用使用脚本绝对路径亦可：

```sh
python scripts/excess_vocab.py --target draft.md --out lexical-report.md --json lexical-report.json
```

有匹配参照时加入目录：

```sh
python scripts/excess_vocab.py --target draft.md --ref reference-texts --out lexical-report.md
```

多个目标文件可放在同一个`--target`之后。已有文件直接读取；只粘贴长稿时，可在当前任务的临时目录保存输入和报告。输出路径须区别于原稿、参照及词库，不覆盖它们。

使用环境现有Python 3，脚本只用标准库。无法执行Python时，仍按词库、模式和原文检查重复，继续完成编辑；执行说明区分人工式检查与工具统计，不补造次数或相对频率。

## 选择词库与参照

默认`--profile general`。额外提供`--profile chatgpt-3.5-study`、`--profile claude-community`或`--profile glm-local-202609`可查看相应历史研究或观察条目；通用条目同时参与。名称表示来源范围，不能直接推广到同品牌的新模型，也不通过稿件文风猜模型。

词库中的`published-corpus-study`来自已发表语料研究；`community-report`来自具体社区观察；`local-editorial-observation`记录本项目小样本或作者偏好；`editorial-pattern`是按语境整理的编辑规则。来源类型随候选输出，模型标签不替代证据。论文中出现频率上升的词，也有准确而必要的专业用法。

参照优先选作者提供的同语言、同文体、相近学科与章节的材料，多位作者可减少单篇风格的影响。混合语言参照按各语言贡献相应统计单位；报告逐块记录有效参照，JSON以`scan_languages`记录实际扫描语言，原有`lang`字段保留主要语言标记。样稿须有可用来源与使用权限；引用、词库和程序输出不作人写参照。只放一篇或主题不匹配时，相对倍数容易受内容词影响；按报告提示将其作为探索线索，不据此给出统计显著性或作者身份结论。

## 把结果用于改稿

1. 先看完整句段。重复的专业术语可能有助于保持指代；套话也可能只出现一次。
2. 对无信息重复、修饰堆叠或空泛动词，依稿内已有内容压缩或改写；对准确术语、作者实质判断和必要限定，保留原意。
3. 按“何时扫描”决定终稿复扫，核对相关位置与前后承接；扫描本身不构成新的改写授权。

不设置通用倍数阈值、词库清零目标、句式配额或AI概率。反复出现也可以保留；编辑意见须说明它在当前段落中造成了什么阅读问题。
